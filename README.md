# Damar Adin Firdaus — Software Engineer Portfolio V5

[![Netlify Status](https://api.netlify.com/api/v1/badges/placeholder/deploy-status)](https://portofolio-damaradinfirdaus.netlify.app/)

Portofolio resmi versi 5 milik **Damar Adin Firdaus**, seorang *Software Engineer* dan *Full-Stack Developer*. Proyek ini menampilkan keahlian dalam pengembangan aplikasi web performa tinggi, arsitektur database, dan desain antarmuka modern.

## 🌐 Demo

**Live Preview**: [https://portofolio-damaradinfirdaus.netlify.app/](https://portofolio-damaradinfirdaus.netlify.app/)

## 🚀 Fitur Utama

- **Modern UI/UX**: Desain minimalis dengan dukungan Dark/Light mode otomatis.
- **Interactive Components**: Animasi halus menggunakan `framer-motion`.
- **Dynamic Projects**: Showcase proyek-proyek unggulan dari pengembangan web hingga infrastruktur jaringan.
- **Typewriter & Code Simulation**: Efek interaktif pada bagian Hero untuk kesan teknologi yang mendalam.
- **Optimized Performance**: Dibangun di atas Vite untuk *build time* yang sangat cepat.

## 🛠️ Tech Stack

- **Framework**: [React.js](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Deployment**: [Netlify](https://www.netlify.com/)

## 📂 Struktur Proyek

- `src/components/`: Komponen UI modular (Hero, Projects, Skills, dll).
- `src/context/`: Manajemen state untuk tema (Light/Dark).
- `src/styles.css`: Konfigurasi global Tailwind CSS.
- `public/`: Aset statis seperti gambar profil, favicon, dan dokumen CV.

## 💻 Cara Menjalankan Secara Lokal

1. **Clone repository**:
   ```bash
   git clone https://github.com/FaramDox/damaradinfirdaus-XportofolioV5.git
   cd damaradinfirdaus-XportofolioV5
   ```

2. **Install dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan server pengembangan**:
   ```bash
   npm run dev
   ```
   Buka `http://localhost:5173` di browser Anda.

4. **Build untuk produksi**:
   ```bash
   npm run build
   ```
